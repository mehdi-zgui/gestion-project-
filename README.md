# 🏙️ Urban Project Management System

## 📌 Description
Application web développée durant un stage, permettant de **gérer les projets urbains et les zones**.

Elle facilite la **planification, le suivi et la gestion des ressources** pour les professionnels.

---

## 🚀 Fonctionnalités

- 📁 Gestion des projets
- 🌍 Gestion des zones urbaines
- 👥 Gestion des utilisateurs
- 🔐 Authentification (Login / Register)
- ✏️ CRUD complet (Create, Read, Update, Delete)
- 🧭 Interface intuitive

---

## 👤 Rôles utilisateurs

- 🧑‍💼 Directeur :
  - Gère les utilisateurs
  - Supervise les projets

- 👷 Agent :
  - Ajoute/modifie projets
  - Gère les zones urbaines

---

## 🛠️ Technologies utilisées

### Frontend
- React.js
- Material-UI

### Backend
- Flask API

### Base de données
- MySQL

---

## 🏗️ Architecture

- Frontend : React
- Backend : Flask
- Database : MySQL
